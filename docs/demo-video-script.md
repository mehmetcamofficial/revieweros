# Evalora ReviewerOS — 3 Minute Demo Script

## 0:00 - 0:20 — Introduction

Hi, this is Evalora ReviewerOS, an observable multi-agent proposal review system built for the Google Cloud Rapid Agent Hackathon, Arize Track.

It helps research offices, universities, accelerators, and funding teams evaluate proposals faster and more consistently.

## 0:20 - 0:50 — Problem

Proposal review is slow, manual, and hard to audit. Reviewers need to assess excellence, impact, feasibility, risk, and funding fit across many documents.

Evalora turns that into a structured AI-assisted workflow.

## 0:50 - 1:30 — Main workflow

Here I log in with the jury demo workspace.

The system provides a proposal review interface where users can analyze proposal content, generate structured reviewer-style outputs, and download reports.

The analysis workflow is designed around Gemini-powered review agents running on Google Cloud infrastructure.

## 1:30 - 2:05 — Admin and governance

Evalora also includes an admin console.

The admin can manage workspaces, quotas, users, access codes, and demo safety controls.

This is important because real AI review systems need operational governance, not just model responses.

## 2:05 - 2:35 — Arize and observability

For the Arize Track, Evalora is designed around observable agent workflows.

The repository includes Arize Phoenix MCP configuration, and the runtime panel is structured around trace-style observability events.

The next production step is to attach every proposal analysis run to Phoenix traces, sessions, and annotations.

## 2:35 - 2:55 — Impact

Evalora can help institutions review proposals faster, reduce inconsistency, and make AI-assisted funding decisions more transparent.

## 2:55 - 3:00 — Closing

This is Evalora ReviewerOS: observable AI proposal review for institutional funding workflows.
